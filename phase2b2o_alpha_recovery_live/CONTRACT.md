This explicit exception permits one fresh Phase 2B2 **NONCLAIM** live operation
with a new task, prompt marker, dispatch token, and logical-operation identity.
The prior terminal `UNKNOWN` remains immutable and unaccepted.

The exact audited alpha, existing ChatGPT login, `exec --ignore-user-config`,
empty MCP override, disabled authority/tool features, read-only sandbox, and
parent-only Genie authority remain mandatory. Raw stdout and stderr must be
durably written and reread before event classification. Exact process-member
images must be retained on both success and failure paths.

Exactly one model process entry is permitted. Any post-entry uncertainty is
terminal with no retry, replacement, alternate launcher, refund, or reset. A
candidate can be accepted only after two-path output agreement, zero observed
tool activity, exact containment evidence, and fresh destination readback. No
reviewer model, Phase 2C, main merge, promotion/freeze, spending, or EXP010.
