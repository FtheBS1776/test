# Phase 2B1 prior-experience correspondence audit

This audit preceded edits on 2026-10-12. It applies the present L7/L2/Genie lineage rather than the broken `integration_experiment` pointer copied into the Phase 2A audit. Relevant sources are `brains10-pass230/PRE_RESEARCH_AUDIT.md`, `active_runner/REVIEW_PLAN.md`, `evidence_summary/CORRESPONDENCE.md`, `run_events/PRIOR_CORRESPONDENCE.md`, `session_driver/PRIOR_CORRESPONDENCE.md`, and the Phase 2A records.

1. **Exact identity is necessary but not authority.** Run/task/input/attempt/slot/call and candidate hashes prevent substitution. They do not prove model execution, provenance, correctness, review independence, currentness, or permission merely because MCP transported them.
2. **Authority, execution, observation, and verification remain separate.** A worker return is an observation. `APPLIED` means one callback returned an allowed acknowledgement; it is not content truth, authenticated execution, task completion, or a review decision generated by this server.
3. **Paths and stores remain host-authoritative.** The tool accepts only a trusted alias plus a previously bound token and exact operation payload. It cannot accept queue, owned-root, module, policy, or generic-operation paths.
4. **Fresh permission cannot be replayed.** The charged Phase 2A run is historical preserved state and is never reused here. A saved token or WAITING/REVIEW state is reconciliation evidence, not permission to launch a replacement worker or reviewer.
5. **UNKNOWN is charged preservation, not retry permission.** A lost response after callback entry may conceal a committed observation, submission, or review. The new projection and server independently require `preserve=true` and `allow_new_invocation=false`; malformed or weakened results become canonical UNKNOWN with no second call.
6. **Review remains separately adjudicated.** The `review` operation applies a caller-supplied decision and checks candidate binding. It does not invoke a reviewer or choose ACCEPT. Separation is a controller procedure, not authenticated caller isolation.
7. **Same-model roles remain common-cause.** Separate future contexts or role labels do not establish independent roots. No model is invoked in Phase 2B1.
8. **Reuse the accepted primitive.** `shared_interfaces/run_events.py` remains byte-identical at SHA-256 `913b4d89bc5bbec0c37141f7914fd111a342d2fced80d25e404d2d25d704f760`; it pins `run_control.py` at `ecc71b088e5a7e3c0bde33b53a7e850dd769daee5b301f2f116edf956599f2d4` and calls `runner.callback` once.
9. **Keep authority surfaces separated.** The event tool is a distinct local stdio process and must never be added to `genie-readonly`, the Phase 2A controller server, or any worker/reviewer context.
10. **MCP annotations are hints.** Accurate write/destructive/non-idempotent metadata can guide a host but cannot replace server-side alias, schema, token, source-pin, and current-state checks. Official sources checked on 2026-10-12: https://developers.openai.com/plugins/build/mcp-server and https://developers.openai.com/api/docs/guides/agents-api/tools/mcp .

## Attacked shortcuts and disposition

- Add event operations to `genie-readonly` or `advance_run`: **REJECT** — collapses separate authority surfaces.
- Let a worker/reviewer see controller or event MCP tools: **REJECT** — it could self-assert trusted observations or decisions.
- Combine observe, submit, and review into one generic/atomic operation: **REJECT** — the accepted core intentionally separates them.
- Treat callback `APPLIED` or transport success as model execution/truth/completion: **REJECT**.
- Retry a callback after UNKNOWN, or refund/reset/replace state: **REJECT**.
- Use the Phase 2A run/token for a Phase 2B callback: **REJECT**.
- Expose `session_driver`, HTTP, a model subprocess, or automatic progression: **DEFER**.
- Use deterministic synthetic values in disposable tests with explicit `NO_MODEL_CALL` labels: **ADAPT** for transport validation only.
