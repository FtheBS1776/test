# Proportional attack and primary research

The reproduced defect is compressed outer input work, separate from decompressed member quotas. A valid archive can include a large prefix while declaring only a two-byte manifest. Old result PASS at67108991 bytes demonstrates missing input cap; it does not establish arbitrary code execution or semantic corruption.

Attack cases: initially oversized regular file; growing/underreported descriptor size; FIFO open blocking before fstat; wrong outer anchor; prefix boundary; symlink to regular input; ZIP parser invoked too early; changed dependency bytes accepted through stale pin. Frozen test checks plus existing CLI regressions and exact pin correspondence adjudicate these finite cases. Preserved source/output hashes prevent retroactively applying this review to old versions.

Cross-check with actual Python3.12 local valid-prefix reproduction, frozen bounded-read/FIFO/anchor tests and exact-source reviewer. No third-party code adopted or new provider experiment.

Limits: O_NONBLOCK is not a general deadline; Windows and remote filesystem behavior unestablished.
