# Roadmap addendum — Phase 2B2A fixture-only boundary

Exit evidence is: exact local path/hash pins, immutable closed argv, isolated-site startup, bounded stdin/stdout/stderr, a minimal rebuilt environment, a fresh non-repository cwd, a committed same-ID launcher claim before spawn, strict output binding, canonical post-claim `UNKNOWN`, and no internal retry.

**Mandatory stop:** do not execute the deferred Codex plan, provision authentication, choose a worker/reviewer model, invoke a provider, expose this launcher over MCP, give a child Genie tools/tokens/paths, apply an event, run `session_driver`, or create automatic progression from this checkpoint.

A separately authorized live Phase 2B2 pilot must first resolve and verify: semantic request redaction; credential boundary; exact model and usage policy; effective child tool/MCP inventory; full runtime/source-closure expectations; descendant process-tree control; stable logical-operation IDs across controller restarts/stores; and fresh destination readback. Worker output remains untrusted, and same-model/same-host review remains common-cause rather than independent proof.

Phase 2C autonomous driving remains later. No main merge, paid API, public endpoint, promotion/freeze, or EXP010 activity follows from this checkpoint.
